# Interaction reference scripts (non-normative)

`working-scripts.json` (19 lines-of-working samples) and `problem-scripts.json` (7 multi-step word problems) are
sample scripts in the `source/components/interaction-script.schema.json` format. They show how recipes compose;
they are played on `Interaction-Catalogue.html`.

- Never load them into authoring context and never copy their numbers, objects or wording into new content.
- Never infer rules, timings or parameters from them; read `source/` instead. Where a sample and the source disagree, the source wins and the sample is a defect.
- They may be replaced at any time without a version change.
